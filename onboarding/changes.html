Identity Chooser

Welcome to version 4.5 of Identity Chooser.

Identity Chooser has been going through a lot of changes over the years, and this new version is no different.

What's new in version 4.5?

Identity Chooser 4.5 comes with a couple of improvements to the chooser popup window.

Keyboard navigation
You can choose the first 9 identities using the corresponding number keys. This feature is enabled for the first 9 email adresses.

If you want to close the window, simply press ESC. This closes both, the popup window the message editor.

Improved scrolling
The Cancel button always stays visible and doesn't scoll down if the list of identities contains a lot of identities.
